trajecto-profiles: Description back to ToC

Trajectory profile classes defined by necessary and sufficient conditions over purpose, navigation pattern, engagement level, interaction types, temporal context and trajectory events. An OWL reasoner assigns them to trajectories. Generated by scripts/generate_profiles_module.py; do not edit by hand.
